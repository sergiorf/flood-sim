# Terrain Library

This directory is the curated terrain library for FloodSim.

It exists to hold reviewed area definitions and provenance notes for real
terrain clips that support demos, screening workflows, and later expansion.

Start small:

- one trusted Brussels demo area
- a few documented candidate source entries
- clear provenance and intended-use notes

See [docs/terrain_library.md](/home/sergio/dev/flood-sim/docs/terrain_library.md:1)
for the protocol.
